## Como identificar uma versão oficial

Cada Release deverá informar, conforme aplicável:

- Nome do aplicativo.
- Número da versão.
- Data da publicação.
- Plataforma e requisitos de compatibilidade.
- Alterações relevantes da versão.
- Nome exato do arquivo de instalação.
- Hash SHA-256 do arquivo para conferência de integridade.
- Informações pertinentes sobre assinatura e instalação.

Não instale um arquivo que não possa ser associado a uma Release
oficial deste repositório.

## Instalação no Android

Quando uma versão Android estiver oficialmente disponível:

1. Abra a Release correspondente.
2. Confira o nome do aplicativo, a versão e os requisitos.
3. Baixe o arquivo de instalação indicado nas notas da Release.
4. Confira as informações de integridade publicadas.
5. Instale somente se confiar na origem e reconhecer a versão.

O Android pode solicitar autorização para instalar aplicativos de
fontes externas. Essa autorização deve ser concedida conscientemente
e somente para uma origem confiável.

## Integridade e segurança

Os arquivos publicados devem ser verificados antes da distribuição.
O hash SHA-256 ajuda a detectar alterações no arquivo, mas, isoladamente,
não comprova a identidade do desenvolvedor nem garante que um aplicativo
seja seguro.

Nunca publique chaves privadas, senhas, tokens de acesso ou arquivos
de assinatura que não sejam destinados à distribuição pública.

## Atualizações
